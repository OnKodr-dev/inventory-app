# Inventory App

Inventory App is a React web application for practicing basic inventory-management UI and frontend application structure.

The project is built with Vite, React, React Router and Tailwind CSS.

## Features

- React single-page application foundation
- Routing with React Router
- Styling setup with Tailwind CSS
- Development, build, preview and lint scripts

## Tech stack

- React
- Vite
- React Router
- Tailwind CSS
- ESLint

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

Run linting:

```bash
npm run lint
```
